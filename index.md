# pdf-ocr — privacy policy

**ქართულად.** ეს არის შიდა, ერთი ადამიანის სამუშაო ინსტრუმენტი, რომელიც Google Drive-ს იყენებს მხოლოდ სურათის ტექსტად ამოკითხვისთვის (OCR). აპი Drive-ზე ტვირთავს დროებით ფაილს, კითხულობს ტექსტს და ფაილს მაშინვე შლის. სხვა ფაილებზე წვდომა არ აქვს (scope: drive.file), მონაცემებს არავის გადასცემს და არ ინახავს.

**English.** pdf-ocr is a private, single-user internal work tool. It uses Google Drive only to extract text from images (OCR): it uploads a temporary file, reads the recognized text and deletes the file immediately. It has no access to any other files (scope: drive.file) and does not store or share any data.
